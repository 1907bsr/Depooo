# GitHub deposunu "Özel" yapma

Depo (github.com/1907bsr/Depooo) şu an **herkese açık**: içindeki
dosyaları (CLAUDE.md, planlar, isimleriniz) herkes görebilir.
Özel yapmak için:

1. Tarayıcıda github.com/1907bsr/Depooo adresini açın (depo sahibi hesapla giriş yapın).
2. Üstteki menüden **Settings** (Ayarlar) sekmesine tıklayın.
3. Sayfanın en altına inin: **Danger Zone** bölümü.
4. **Change repository visibility** → **Change visibility** butonuna tıklayın.
5. **Make private** seçin, çıkan pencerede istenen onayı verin.

Not: Daha önce açık olduğu için içerik bir yerde kopyalanmış olabilir.
Henüz depoda şifre veya anahtar yok; .env zaten depoya girmeyecek şekilde ayarlı.

İsterseniz depo adını da değiştirebilirsiniz (Settings → General → Repository name),
örneğin kanal adı belli olunca.
