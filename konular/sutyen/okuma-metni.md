# Okuma Metni – Sütyeni Kim Buldu? (TASLAK 2 – daha esprili)

İşaretler:
- `/` kısa durak · `//` uzun durak (espriden önce bekleme)
- **kalın** = vurgu
- **[güler]** = kısa, doğal bir kıkırdama ya da gülümseyerek söyleme. Zorla gülmeyin; içinizden gelirse gülün.
- [okunuş] = yabancı isim nasıl okunur

Bilgiler TASLAK 1 ile aynıdır (kaynaklar: senaryo.md, kaynakca.md). Sadece anlatım daha komik.
Şakalar her zaman şaka olduğu belli olacak şekilde yazıldı; uydurma bilgi yoktur.

---

## 1. Açılış
New York. / 1910'ların başı. / Büyük bir balo var.

Genç bir kadın aynanın karşısında hazırlanıyor. / Saç tamam. / Elbise tamam. / Özgüven… / tamam. //
Tek bir sorun var: / Altındaki **korse.** //

Korse dediğimiz şey; / balina çubuğu, / metal tel / ve bağcıktan yapılmış, / nefes almayı **"isteğe bağlı"** hale getiren bir iç çamaşırı. //
Yani düşünün: / Sabah giyiyorsunuz, / akşam çıkarıyorsunuz, / arada bir yerde / ciğerleriniz **istifa ediyor.** [güler] //

Üstüne bir de bu çubuklar / ince elbisenin altından / resmen **dışarı bakıyor.** /
Sanki elbisenin içinde / küçük bir şemsiye taşıyor. //

Kadın aynaya bakıyor / ve tarihe geçecek o cümleyi kuruyor: / **"Ben bununla dans etmem."** //

Hizmetçisini çağırıyor: / "Bana iki mendil getir. / Bir de kurdele." //
Hizmetçi muhtemelen şöyle düşünüyor: / "Eyvah, / hanımefendi ağlayacak." //
Ama hayır. / Hanımefendi… / **tarih yazacak.** //

Ama durun. / Çünkü bu kadın sütyeni ilk bulan kişi **değil.** /
Avusturya'da bir şatonun altında / beş yüz yıl saklanmış bir sır var. /
Ve ortada bütün dünyayı kandırmış / "Otto" diye bir mucit var… / ki kendisi **hiç yaşamadı.** //

Bugün NasılOldu'da: / **Sütyeni gerçekten kim buldu?**

## 2. Sütyen yokken hayat
Önce şu soruyu soralım: / Sütyen yokken kadınlar ne yapıyordu? //
Cevap basit: / **Bir bez buluyorlardı.** [güler] //

Antik Yunan'da kadınlar göğüslerine kumaş bir bant sarıyordu. / Adı: / **apodesmos.** [apodesmos] //
Evet, / kulağa ilaç adı gibi geliyor. / "Günde iki apodesmos, / tok karnına." [güler] //

Romalılar da benzer bir bant kullanmış / ama adını **strophium** [strofyum] koymuş. /
Yani ürün aynı, / ambalaj yeni. / Pazarlamanın atası / Romalılar. //

Hatta Sicilya'da, / bin yedi yüz yıllık bir Roma villasında / bir mozaik var: /
Bir grup kadın. / Bantlar takılmış, / şortlar giyilmiş, / top oynanıyor, / ağırlık kaldırılıyor. //
İnsanlar buna "Bikinili Kızlar" diyor / ama aslında bunlar mayo değil… / **spor kıyafeti.** /
Yani bin yedi yüz yıl önce bile / birileri "spor salonuna ne giysem" derdindeymiş. [güler] //

Sonra ne oldu? /
Avrupa yüzyıllar boyunca oturdu / ve şunu düşündü: / "Bu bant çok rahat. // Bunu nasıl **daha zor** yaparız?" //

Ve korse geldi. /
Eğilemiyorsun. / Oturmak bir mühendislik projesi. / Merdiven çıkmak? / **Ekstrem spor.** //
Yemek mi? / Üçüncü lokmada dikişler / sendika kurup **greve çıkıyor.** [güler] //

Ve bu durum / tam **üç yüz yıl** sürdü. /
Üç yüz yıl boyunca kimse çıkıp / "Arkadaşlar… / biz bunu neden giyiyoruz?" demedi. //
Ta ki…

## 3. Şatodaki sır
…iki bin sekiz yılına kadar. /
Avusturya. / Doğu Tirol. / **Lengberg** [Lengberg] Şatosu. //

Şatoda tadilat var. / İşçiler bir zemini açıyorlar. / Ve altından… / **çöp** çıkıyor. //
Ama sıradan çöp değil. / **Beş yüz yıllık** çöp. /
Yani Orta Çağ'ın / "bunu sonra atarız" dediği her şey. [güler] //

Yaklaşık iki bin yedi yüz parça kumaş. /
Arkeologlar tek tek inceliyor / ve bir tanesini görünce / **donup kalıyorlar.** //
Çünkü ellerindeki şey… / resmen bir **sütyen.** / Keten. / İki kaplı. / Askılı. //
Bugün bir mağazada görseniz / "biraz retro ama güzel" der, / indirimdeyse alırdınız. [güler] //

Karbon testi yapılıyor. / Sonuç: / **On beşinci yüzyıl.** //
Yani tarih kitapları "sütyen bin dokuz yüzlerde icat edildi" derken, /
Orta Çağ'da bir kadın bunu çoktan giymiş, / yıkamış, / eskitmiş / ve **çöpe atmış.** [güler] //

Peki bu fikir neden unutuldu? /
Çünkü moda tarihini tek cümleyle özetleyebiliriz: / **Korse geri döndü.** /
Tıpkı / kötü bir eski sevgili gibi. [güler]

## 4. Paris'ten ilk hamle
Bin sekiz yüz seksen dokuz. / Paris. /
Bütün şehir yeni yapılan Eyfel Kulesi'ne bakıyor. / Ama biz / küçük bir terzi dükkânına bakacağız. //

Herminie Cadolle [Ermini Kadol] adında bir kadın / korseyi alıyor / ve makası basıyor: / **ortadan ikiye.** //
Alt kısım beli sarıyor, / üst kısım göğsü taşıyor. /
Ve tarihte ilk kez / nefes almak / "isteğe bağlı" olmaktan **çıkıyor.** //
Yani Cadolle korseyi kaldırmıyor. / Ama onunla / bir **ateşkes** imzalıyor. [güler] //

Birkaç yıl içinde üst parça ayrı satılmaya başlıyor. /
Ve Cadolle'un [Kadol'un] markası / bugün hâlâ Paris'te, / hâlâ ailesinin elinde. //

Peki o zaman sütyeni Cadolle mu buldu? / Belki. /
Ama "patentli modern sütyen" denince / akla başka bir isim geliyor.

## 5. Mendiller ve patent
Açılıştaki genç kadına dönelim. / Adı: / **Mary Phelps Jacob.** [Meri Felps Ceykıb] //

İki mendil, / bir kurdele, / biraz iğne iplik. /
Hizmetçisiyle birlikte birkaç dakikada bir şey dikiyor. / Giyiyor. / Ve… // **oluyor!** /
Çubuk yok, / tel yok, / ızdırap yok. / Ciğerler / işe geri dönüyor. [güler] //

Anlatılana göre baloda arkadaşları hemen soruyor: / "Bu ne? / Bana da yapar mısın?" /
Ve Mary o an anlıyor: / Bu bir elbise meselesi değil. / Bu bir **iş fikri.** //

On iki Şubat bin dokuz yüz on dörtte / patent başvurusu yapıyor. / Kasım ayında patent onaylanıyor. /
Patentin adı tek kelime: / **"Brassière."** [Brasiyer] // Yani… / sütyen. / Kısa, / net, / iddialı. //

Ama bir fikri patentlemek başka, / onu bütün dünyaya satmak başka. /
Sonunda Mary patenti / büyük bir şirkete satıyor: / Warner Brothers [Vorner Bradırs]. //
Bir **korse** şirketi. // Yani… / patenti **düşmana** satıyor. [güler] //

Fiyat? / Sıkı durun… // **bin beş yüz dolar.** //
Söylenene göre şirket bu patentten / sonraki otuz yılda / **on beş milyon dolardan fazla** kazanıyor. //
Yani Mary'nin eline geçen, / şirketin kazandığının / **binde biri bile değil.** /
Bunu okuyunca / Mary'nin yerine biz üzüldük. / Hatta biraz / **biz sinirlendik.** [güler] //

Ama üzülmeyin. /
Mary sonra adını Caresse Crosby [Kares Krosbi] yapıyor, / Paris'e taşınıyor / ve son derece bohem, / son derece renkli bir hayat sürüyor. /
Onun hikâyesi / başlı başına bir video.

## 6. Efsane mi, gerçek mi?
Şimdi biraz oyun oynayalım: / **Efsane mi, / gerçek mi?** //

**Bir:** / "Birinci Dünya Savaşı'nda kadınlar korseyi bıraktı, / o çelikle de savaş gemisi yapıldı." //
Anlatılana göre bin dokuz yüz on yedide Amerika'da / kadınlardan korse almamaları istenmiş / ve yirmi sekiz bin ton çelik kazanılmış. /
Hatta bunun iki savaş gemisine yettiği bile söylenir. //
Ama… / kurulun kendi raporunda / korseden **hiç** bahsedilmiyor. / Bazı tarihçilere göre / bu büyük ölçüde **abartı.** //
Yani kadınlar korseyi bıraktı mı? / Evet. / Korselerden gemi mi yapıldı? / O kısım… // biraz **süslenmiş.** /
Hikâyeye de korse giydirmişler. [güler] //

**İki:** / "Sütyeni Otto Titzling [Otto Titzling] adında bir Alman buldu." //
Bunu birçok yerde okuyabilirsiniz. / Ünlü bir bilgi yarışması oyununda / soru olarak bile çıktı. //
Tek sorun şu: / Otto Titzling… // **hiç yaşamadı.** //
Bin dokuz yüz yetmiş birde / Wallace Reyburn [Volıs Reybırn] adında bir mizahçı / tamamen uydurma bir kitap yazdı. /
Kahramanının adı da İngilizcede… / diyelim ki / biraz **açık saçık** bir kelime oyunu. //
Yani adam şaka yaptı, / dünya **ciddiye aldı.** / İnternetten önceki zamanların / sahte haberi. [güler] //

**Üç:** / "Bin dokuz yüz altmış sekizde feministler sokakta sütyen yaktı." //
O yıl Amerika'da bir güzellik yarışması protesto ediliyor. /
Kadınlar sütyenleri, / korseleri, / takma kirpikleri / bir "Özgürlük Çöp Kutusu"na atıyor. //
Plan: / kutuyu yakmak. / Ama polis diyor ki: / "Hanımlar, / burası tahta iskele. / Yakarsanız / bütün sahili yakarsınız." / Ve **izin vermiyor.** //
Sonra bir gazete "Sütyen yakanlar" diye başlık atıyor… / ve efsane **doğuyor.** /
Yani o gün yanan tek şey… // bir gazetecinin **hayal gücüydü.** [güler] //
Gerçi bir muhabir yıllar sonra / kutudan biraz duman çıktığını hatırladığını söylemiş. /
Ama o meşhur "sokakta sütyen yakma" sahnesi / büyük ölçüde bir gazete başlığının eseri.

## 7. Kapanış
Peki sütyeni kim buldu? //
Kısa cevap: / **Tek bir kişi değil.** //

Antik Yunanlılar bandı buldu. / Romalılar ona yeni bir isim verdi. /
Orta Çağ'da biri kaplısını yaptı / ve çöpe attı. /
Cadolle korseyle ateşkes imzaladı. /
Mary de iki mendille patenti aldı… / ve bin beş yüz dolara sattı. //

Yani sütyen bir icat değil… // bir **isyan.** /
Yüzyıllar boyunca / "Bu korse beni öldürecek" diyen kadınların isyanı. //

Bu arada… / Otto'yu uyduran Wallace Reyburn'ü [Volıs Reybırn'ü] hatırlıyor musunuz? /
O adam / bir kitap daha yazdı. / Ve o kitap yüzünden dünya / hâlâ **tuvaleti kimin icat ettiğini** yanlış biliyor. //

Bir sonraki videoda: / tuvaletin gerçek hikâyesi. /
Size söz veriyorum: / sifonu çekmeden önce / **iki kere** düşüneceksiniz. [güler] //

Sizce bir sonraki icat ne olsun? / Yorumlara yazın. / En çok istenen konu / bir sonraki videoda. //

Görüşmek üzere. / Ve unutmayın: / Nefes almak… // **isteğe bağlı değildir.** [güler]
