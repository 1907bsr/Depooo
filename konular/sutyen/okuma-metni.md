# Okuma Metni – Sütyeni Kim Buldu?

Seslendirilecek versiyon (senaryo.md TASLAK 1'den).
İşaretler: `/` kısa durak · `//` uzun durak (espri zamanlaması) · **kalın** = vurgu · [okunuş] = yabancı isim nasıl okunur
Yapay ses için: [okunuş] köşeli parantezdeki hali sese yazdırılacak, orijinal yazılış ekranda görünecek.

---

## 1. Açılış
New York. / 1910'ların başı. / Büyük bir balo var.

Genç bir kadın aynanın karşısında hazırlanıyor. / Elbise harika. / İnce, / şık, / dekolteli.
Tek bir sorun var. //

Altındaki **korse.**
Balina çubuklarından yapılmış, / nefes almayı **"isteğe bağlı"** hale getiren bir iç giyim. //
Ve bu çubuklar… / ince elbisenin altından / resmen **dışarı bakıyor.** //

Kadın aynaya bakıyor / ve diyor ki: / **"Ben bununla dans etmem."** //

Hizmetçisini çağırıyor. / "Bana iki mendil getir. / Biraz da kurdele." //

Ve o gece… / iç çamaşırı tarihi **değişiyor.** //

Ama durun. / Çünkü bu kadın, / sütyeni ilk bulan kişi **değil.** /
Avusturya'da bir şatonun dibinde / 500 yıl saklanmış bir sır var. /
Ve ortada, bütün dünyayı kandırmış / "Otto" diye bir mucit var… / ki kendisi **hiç yaşamadı.** //

Bugün NasılOldu'da: / **Sütyeni gerçekten kim buldu?**

## 2. Sütyen yokken hayat
Önce bir soru: / Sütyen yokken kadınlar ne yapıyordu? //
Cevap: / **Yaratıcı oluyorlardı.** //

Antik Yunan'da kadınlar göğüslerine bir kumaş bant sarıyordu. /
Adı da çok romantik: / **apodesmos.** [apodesmos] //

Romalılar da "biz daha iyisini yaparız" demiş / ve buna **strophium** [strofyum] demişler. /
Yani aynı bant, / daha havalı bir isim. / Roma'nın klasik hareketi. //

Hatta Sicilya'da, / yaklaşık bin yedi yüz yıllık bir Roma villasında / şöyle bir mozaik var: /
Bir grup kadın. / Üstlerinde bant, / altlarında şort gibi bir şey. / Top oynuyorlar, / ağırlık kaldırıyorlar. //

İnsanlar buna "Bikinili Kızlar" diyor. / Ama aslında bunlar mayo değil… / **spor kıyafeti.** /
Yani bin yedi yüz yıl önce bile / birileri spor sütyeni mantığını **çözmüştü.** //

Sonra ne oldu? /
Avrupa yüzyıllar boyunca şunu düşündü: / "Bu bant çok rahat. // Bunu daha **zor** nasıl yaparız?" //

Ve korse geldi. /
Balina çubukları, / metal teller, / sıkı sıkı bağcıklar. /
Eğilemiyorsun. / Oturmak bir mühendislik projesi. /
Yemek mi? / İki çatal fazla yersen / dikişler **isyan ediyor.** //

Korse üç yüz yıl boyunca modanın patronu oldu. / Kimse "bu saçmalık" demeye cesaret edemedi. //
Ta ki…

## 3. Şatodaki sır
…ta ki iki bin sekiz yılına kadar. /
Avusturya'nın dağlık bölgesi, / Doğu Tirol. / **Lengberg** [Lengberg] Şatosu. //

Şatoda tadilat yapılıyor. / İşçiler bir zemini açıyorlar / ve altından… / **çöp** çıkıyor. //
Ama sıradan çöp değil. / **Beş yüz yıllık** çöp. //

Yaklaşık iki bin yedi yüz parça kumaş. /
Arkeologlar tek tek inceliyor / ve bir tanesini görünce / **donup kalıyorlar.** //

Çünkü ellerindeki şey… / resmen bir **sütyen.** /
Keten kumaştan, / iki ayrı kaplı, / askılı. /
Bugün bir mağazada görseniz / "biraz retro" deyip geçersiniz. //

Karbon testi yapılıyor. / Sonuç: / **On beşinci yüzyıl.** //

Yani tarih kitapları "sütyen bin dokuz yüzlerde icat edildi" derken, /
Orta Çağ'da bir kadın bunu çoktan giyiyormuş. /
Ve muhtemelen "Ne var bunda?" diyormuş. //

Peki o zaman bu fikir neden unutuldu? /
Çünkü moda tarihi bazen tek cümleyle özetlenir: / **korse geri döndü.**

## 4. Paris'ten ilk hamle
Bin sekiz yüz seksen dokuz. / Paris. /
Herkes yeni yapılan Eyfel Kulesi'ne bakıyor. / Ama biz bir terzi dükkânına bakacağız. //

Herminie Cadolle [Ermini Kadol] adında bir kadın, / korseyi alıyor / ve **ortadan ikiye bölüyor.** /
Alt kısım beli sarıyor, / üst kısım göğsü taşıyor. //

Yani "korseyi kaldıralım" demiyor. /
"Korseyi ikiye bölelim, / en azından **nefes alalım**" diyor. /
Küçük ama devrim gibi bir adım. //

Birkaç yıl içinde o üst parça ayrı satılmaya başlıyor. /
Ve Cadolle'un [Kadol'un] kurduğu marka / bugün hâlâ Paris'te, / hâlâ ailesinin elinde. //

Peki o zaman sütyeni Cadolle mu buldu? / Belki. /
Ama "patentli modern sütyen" denince akla gelen isim / başka.

## 5. Mendiller ve patent
Açılıştaki genç kadına geri dönelim. /
Adı: / **Mary Phelps Jacob.** [Meri Felps Ceykıb] //

İki mendil, / bir kurdele, / biraz iğne iplik. /
Hizmetçisiyle birlikte birkaç dakikada bir şey dikiyor. / Elbisenin altına giyiyor. / Ve… // **oluyor!** /
Çubuk yok, / metal yok, / ızdırap yok. //

Anlatılana göre baloda arkadaşları hemen soruyor: / "Bu ne? / Bana da yapar mısın?" //
Ve Mary burada çok önemli bir şey fark ediyor: / **Herkes bunu istiyor.** //

On iki Şubat bin dokuz yüz on dörtte / patent başvurusu yapıyor. /
Aynı yılın Kasım ayında / patenti alıyor. /
Patentin adı: / "Sırtı Açık Sütyen." //

Ama bir fikri patentlemek başka, / onu bütün dünyaya satmak başka. /
Ve sonunda patenti büyük bir korse şirketine, / Warner Brothers [Vorner Bradırs] şirketine satıyor. //

Fiyat? / Sıkı durun… // **bin beş yüz dolar.** //

Söylenene göre şirket bu patentten / sonraki otuz yılda / **on beş milyon dolardan fazla** kazanıyor. //

Yani Mary, / dünyanın en çok satan iç çamaşırlarından birinin fikrini satmış… /
ve eline geçen para, / şirketin kazandığının **binde biri bile değil.** //

Ama üzülmeyin. /
Mary sonra adını Caresse Crosby [Kares Krosbi] yapıyor, / Paris'e taşınıyor / ve son derece bohem, / son derece renkli bir hayat sürüyor. /
Hayatının hikâyesi / başlı başına bir video.

## 6. Efsane mi, gerçek mi?
Şimdi biraz oyun oynayalım. /
Sütyen hakkında herkesin bildiği üç bilgi var. / Bakalım hangileri doğru. //

**Bir:** / "Birinci Dünya Savaşı'nda kadınlar korseyi bıraktı, / bu sayede savaş gemisi yapıldı." //
Anlatılana göre bin dokuz yüz on yedide Amerika'da / kadınlardan korse almamaları istenmiş / ve böylece yirmi sekiz bin ton çelik kazanılmış. /
Hatta bunun iki savaş gemisine yettiği bile söylenir. //
Ama… / kurulun kendi raporunda / korseden **hiç** bahsedilmiyor. /
Bazı tarihçiler bunun büyük ölçüde **abartı** olduğunu söylüyor. //
Kadınlar korseyi bıraktı mı? / Evet, / giderek bıraktı. /
Gemi mi oldu? / O kısım biraz… // **süslenmiş.** //

**İki:** / "Sütyeni Otto Titzling [Otto Titzling] adında bir Alman buldu." //
Bunu birçok yerde okuyabilirsiniz. / Ünlü bir bilgi yarışması oyununda bile soru olarak çıktı. //
Tek sorun şu: / Otto Titzling… // **hiç yaşamadı.** //
Bin dokuz yüz yetmiş birde / Wallace Reyburn [Volıs Reybırn] adında bir mizahçı / tamamen uydurma bir kitap yazdı. /
Kahramanının adı da İngilizcede… / diyelim ki / biraz **açık saçık** bir kelime oyunu. /
Ve insanlar buna inandı. / Hem de **yıllarca.** //

**Üç:** / "Bin dokuz yüz altmış sekizde feministler sokakta sütyen yaktı." //
O yıl Amerika'da bir güzellik yarışması protesto ediliyor. /
Kadınlar sütyenlerini, / korselerini, / takma kirpiklerini / bir "Özgürlük Çöp Kutusu"na atıyorlar. //
Plan aslında kutuyu yakmak. /
Ama polis / "Burası tahta iskele, / yakarsanız her yer tutuşur" diyerek / **izin vermiyor.** /
Sonra bir gazete "Sütyen yakanlar" diye başlık atıyor… / ve efsane **doğuyor.** //
Bir muhabir yıllar sonra / kutudan duman çıktığını hatırladığını söylemiş. /
Ama "sokakta sütyen yakma" sahnesi / büyük ölçüde bir gazete başlığının eseri.

## 7. Kapanış
Peki sütyeni kim buldu? //
Kısa cevap: / **Tek bir kişi değil.** //

Antik Yunanlılar bandı buldu. /
Orta Çağ'da bir kadın kaplı modelini çoktan giyiyordu. /
Cadolle [Kadol] korseyi ikiye böldü. /
Mary Phelps Jacob [Meri Felps Ceykıb] da iki mendille onu patentledi… / ve bin beş yüz dolara sattı. //

Yani sütyen bir icat değil… // bir **isyan.** /
Yüzyıllar boyunca "Bu korse beni öldürecek" diyen kadınların isyanı. //

Bu arada… / Otto'yu uyduran Wallace Reyburn'ü [Volıs Reybırn'ü] hatırlıyor musunuz? /
O adamın bir kitabı daha var. /
Ve o kitap yüzünden dünya / hâlâ **tuvaleti kimin icat ettiğini** yanlış biliyor. //

Bir sonraki videoda: / Tuvaletin gerçek hikâyesi. /
Ve size söz veriyorum… / sifonu çekmeden önce / **iki kere** düşüneceksiniz. //

Sizce bir sonraki icat ne olsun? / Yorumlara yazın. / En çok istenen konu, / bir sonraki videoda.
