# Okuma Metni – Sütyeni Kim Buldu? (TASLAK 3.3)

İşaretler:
- `/` kısa nefes · `//` uzun durak (espriden önce bekleme)
- **kalın** = vurgu
- **[güler]** = içinden gelirse kısa bir kıkırdama ya da gülümseyerek söyle
- (parantez) = yabancı ismin, para tutarının ya da büyük sayının okunuşu; parantez içini okuyacaksın

Yazım: Bütün sayılar rakamla. Para tutarlarının okunuşu parantezde. Bilgiler önceki taslaklarla aynıdır
(kaynaklar: senaryo.md, kaynakca.md). Yorum çağrısı sadece sondadır.

---

## 1. Açılış
Yıl 1913. / New York (Nyu York). //

Sen 20 yaşında, / sosyetenin göz bebeği bir kızsın. /
Bu akşam şehrin en havalı balosu var. / Davetiye cebinde, / elbisen hazır, / özgüvenin **tavan.** //

Tek bir pürüz var: / Üstündeki **korse.** //

Balina kemiğinden, / metal telden / ve bağcıktan yapılmış bu alet / nefes almayı **"isteğe bağlı"** hâle getiriyor. /
Eğilemiyorsun, / oturamıyorsun. / 3 lokma fazla yesen / dikişler **grev ilan eder.** [güler] //

Üstelik çubuklar / ince elbisenin altından / cartlı curtlu **dışarı fırlamış.** /
Sanki elbisenin içinde / şemsiye taşıyorsun. //

Aynaya bakıyorsun / ve tarihe geçecek o lafı patlatıyorsun: / **"Ben bununla dans etmem!"** //

Hizmetçini çağırıyorsun: / "Bana 2 mendil getir. / Bir de kurdele." //
Kadıncağız muhtemelen şöyle düşünüyor: / "Eyvah, / hanımefendi ağlayacak." //
Ama hayır. / Hanımefendi ağlamayacak. / Hanımefendi… / **tarih yazacak.** //

Yalnız bir dakika. / Sütyeni ilk bulan aslında **sen değilsin.** /
Avusturya'da bir şatonun altında / 500 yıldır bekleyen bir sır var. /
Bir de bütün dünyayı kandıran / Otto adında bir mucit var… / üstelik kendisi **hiç yaşamadı.** //

Bugün Büş'ten Dinle'de: / **Sütyeni gerçekten kim buldu?**

## 2. Sütyen yokken hayat
Şimdi düşün: / Sütyen yokken kadınlar ne yapıyordu? //
Cevap basit: / **Bir bez buluyorlardı.** [güler] //

Antik Yunan'da kadınlar / göğüslerine kumaştan bir bant sarıyordu. / Adı: / **apodesmos.** //
Evet, / kulağa öksürük şurubu gibi geliyor: / "Günde 2 apodesmos, / tok karnına." [güler] //

Romalılar da benzer bir bant kullanmışlar / ama adını **strophium** (strofyum) koymuşlar. /
Yani mal aynı, / etiket yeni. / Pazarlamanın piri de / Romalılar. //

Hatta Sicilya'da / 1.700 (bin yedi yüz) yıllık bir Roma villasında / bir mozaik var. /
Mozaikte bir grup kadın görüyorsun: / Göğüslerinde bant, / altlarında şort. / Kimi top oynuyor, / kimi ağırlık kaldırıyor. //
Herkes buna "Bikinili Kızlar" diyor / ama bunlar mayo değil… / **spor kıyafeti.** /
Yani 1.700 (bin yedi yüz) yıl önce bile / kadınlar "Spora giderken ne giysem?" derdindeymiş. [güler] //

Peki sonra ne oldu? /
Avrupa yüzyıllarca oturdu / ve şunu düşündü: / "Bu bant çok rahat. // Bunu nasıl **daha zor** hâle getiririz?" //

Ve korse sahneye çıktı. /
Eğilmek yasak. / Oturmak bir mühendislik projesi. / Merdiven çıkmak mı? / **Ekstrem spor.** //

Velhâsıl kelâm, / bu işkence tam **300 yıl** sürdü. /
300 yıl boyunca kimse çıkıp / "Arkadaşlar… / biz bunu neden giyiyoruz?" demedi. //
Ta ki…

## 3. Şatodaki sır
…2008 yılına kadar. /
Avusturya. / Doğu Tirol. / **Lengberg** Şatosu. //

Şatoda tadilat var. / İşçiler bir zemini kaldırıyor / ve altından… / **çöp** çıkıyor. //
Ama öyle sıradan bir çöp değil. / **500 yıllık**, / halis muhlis / Orta Çağ çöpü. /
Yani Orta Çağ'ın "Bunu sonra atarız." dediği ne varsa. [güler] //

Yaklaşık 2.700 (iki bin yedi yüz) parça kumaş çıkıyor. /
Arkeologlar bunları tek tek inceliyorlar / ve bir tanesini görünce / **donup kalıyorlar.** //
Çünkü ellerindeki şey… / düpedüz bir **sütyen.** / Keten. / 2 kaplı. / Askılı. //
Bugün bir mağazada görsen / "Biraz retro ama fena değil." dersin, / indirimdeyse kaparsın. [güler] //

Karbon testi yapılıyor. / Sonuç: / **15. yüzyıl.** //
Yani tarih kitapları "Sütyen 1900'lerde icat edildi." diye racon keserken / Orta Çağ'da bir kadın bunu çoktan giymiş, / yıkamış, / eskitmiş / ve **çöpe atmış.** [güler] //

Peki bu fikir neden unutuldu? /
Çünkü moda tarihi tek cümleden ibaret: / **Korse geri döndü.** /
Hem de kötü bir eski sevgili gibi, / hiç çağrılmadan. [güler]

## 4. Paris'ten ilk hamle
Yıl 1889. / Paris. /
Bütün şehir yeni dikilen Eyfel Kulesi'ne bakıyor. / Biz ise / küçük bir terzi dükkânına bakacağız. //

Herminie Cadolle (Ermini Kadol) adında bir kadın / korseyi tezgâha yatırıyor / ve makası basıyor: / **Ortadan ikiye!** //
Alt kısım beli sarıyor, / üst kısım göğsü taşıyor. /
Ve tarihte ilk kez / nefes almak / "isteğe bağlı" olmaktan **çıkıyor.** //
Yani Cadolle (Kadol) korsenin fişini çekmiyor / ama onunla bir **ateşkes** imzalıyor. [güler] //

Birkaç yıl içinde o üst parça / ayrı olarak satılmaya başlıyor. /
Üstelik Cadolle'un (Kadol'un) kurduğu marka / bugün hâlâ Paris'te / ve hâlâ ailesinin elinde. //

Peki sütyeni Cadolle (Kadol) mu buldu? / Olabilir. /
Ama "patentli modern sütyen" deyince / akla başka bir isim geliyor. //
Senin adın.

## 5. Mendiller ve patent
Açılıştaki baloya dönelim. / Evet, / o kız sensin: / **Mary Phelps Jacob** (Meri Felps Ceykıb). //

2 mendil, / bir kurdele, / biraz da iğne iplik. /
Hizmetçinle birlikte / birkaç dakikada bir şey dikiyorsun. / Giyiyorsun / ve… // **oluyor!** /
Çubuk yok, / tel yok, / ızdırap yok. / Ciğerlerin / işe geri dönüyor. [güler] //

Anlatılana göre baloda arkadaşların etrafını sarıyor: / "Bu ne? / Bana da yapar mısın?" /
İşte o an jeton düşüyor: / Bu bir elbise meselesi değil, / bir **iş fikri.** //

12 Şubat 1914'te / patent başvurusu yapıyorsun. / Aynı yılın kasım ayında / patent onaylanıyor. /
Patentin adı tek kelime: / **"Brassière"** (Brasiyer). // Yani… / sütyen. / Kısa, / net, / iddialı. //

Ama bir fikrin patentini almak başka, / onu bütün dünyaya satmak başka. /
Sonunda patenti / büyük bir şirkete satıyorsun: / Warner Brothers'a (Vorner Bradırs'a). //
Bir **korse** şirketine. // Yani patenti / resmen **düşmana** satıyorsun. [güler] //

Fiyatı mı? / Sıkı dur… // **1.500 dolar** (bin beş yüz dolar). //
Söylenene göre şirket / bu patentten sonraki 30 yılda / **15.000.000 dolardan** (on beş milyon dolardan) fazla kazanıyor. //
Yani senin cebine giren para / onların kazandığının / **binde biri bile değil.** /
Bunu okuyunca / senin yerine biz sinirlendik. / Hem de / **bayağı.** [güler] //

Ama üzülme. /
Sonra adını Caresse Crosby (Kares Krosbi) yapıyorsun, / Paris'e yerleşiyorsun / ve son derece bohem, / son derece renkli bir hayat sürüyorsun. /
O hikâye de / başlı başına bir video.

## 6. Efsane mi, gerçek mi?
Şimdi biraz oyun oynayalım: / **Efsane mi, / gerçek mi?** //

**1:** / "Sütyeni Otto Titzling (Otto Titsling) adında bir Alman buldu." //
Bunu bir sürü yerde okuyabilirsin. / Ünlü bir bilgi yarışması oyununda / soru olarak bile çıktı. //
Tek bir sorun var: / Otto Titzling (Otto Titsling)… // **hiç yaşamadı.** //
1971'de / Wallace Reyburn (Volıs Reybırn) adında bir mizahçı / tamamen uydurma bir kitap yazdı. /
Kitabın kahramanının adı da İngilizcede… / diyelim ki / biraz **açık saçık** bir kelime oyunu. //
Yani adam şaka yaptı, / dünya **ciddiye aldı.** / İnternetten önceki zamanların / sahte haberi. [güler] //

**2:** / "1968'de feministler sokakta sütyen yaktı." //
O yıl Amerika'da / bir güzellik yarışması protesto ediliyor. /
Kadınlar sütyenlerini, / korselerini, / takma kirpiklerini / bir "Özgürlük Çöp Kutusu"na atıyor. //
Plan şu: / Kutuyu ateşe vermek. / Ama polis diyor ki: / "Hanımlar, / burası tahta bir iskele. / Yakarsanız / bütün sahili yakarsınız." / Ve **izin vermiyor.** //
Sonra bir gazete / "Sütyen yakanlar" diye manşet atıyor… / ve efsane **doğuyor.** /
Yani o gün yanan tek şey… // bir gazetecinin **hayal gücüydü.** [güler] //
Gerçi bir muhabir yıllar sonra / kutudan biraz duman çıktığını hatırladığını söylemiş. /
Ama o meşhur "sokakta sütyen yakma" sahnesi / büyük ölçüde bir gazete manşetinin eseri.

## 7. Kapanış
Peki sütyeni kim buldu? //
Kısa cevap: / **Tek bir kişi değil.** //

Antik Yunanlılar bandı buldu. / Romalılar etiketini değiştirdi. /
Orta Çağ'da biri kaplısını dikti / ve çöpe attı. /
Cadolle (Kadol) korseyle ateşkes imzaladı. /
Mary (Meri) de 2 mendille patenti aldı… / ve 1.500 dolara (bin beş yüz dolara) sattı. //

Yani sütyen bir icat değil… // bir **isyan.** /
Yüzyıllar boyunca "Bu korse beni öldürecek!" diyen kadınların isyanı. //

Bu arada… / Otto'yu uyduran Wallace Reyburn'ü (Volıs Reybırn'ü) hatırladın mı? /
O adam / bir kitap daha yazdı. / Ve o kitap yüzünden dünya / hâlâ **tuvaleti kimin icat ettiğini** yanlış biliyor. //

Bir sonraki videoda: / Tuvaletin gerçek hikâyesi. /
Sana söz veriyorum: / Sifonu çekmeden önce / **2 kere** düşüneceksin. [güler] //

Ondan sonrakini de / **sen seç!** / Topuklu ayakkabıyı kim buldu? / Çatalı kim buldu? / Yoksa tuvalet kâğıdı icat edilmeden önce / insanlar ne kullanıyordu? / Yorumlara yaz; / en çok istenen konu / sıradaki videolardan biri olacak. //

Görüşmek üzere. / Ve unutma: / Nefes almak… // **isteğe bağlı değildir.** [güler]
